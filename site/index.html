03

Four outcomes. One JSON.

A narrow contract that an agent can act on — with the uncertainty left visible.

success

Positive evidence that the operation completed.

failure

A concrete assertion, build or application failure.

blocked

Permissions, dependencies, network or environment prevented execution.

unknown

Zero tests, skipped work, dry runs, truncation or insufficient evidence.

05

Useful signal. Not absolute truth.

Verdict is an advisory classifier trained on synthetic, English-biased CLI output. It does not prove task completion, code correctness or safety. Keep deterministic checks and authoritative environment-state verification as the source of truth.
